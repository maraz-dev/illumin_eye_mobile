# Illumin Eye Mobile

## Project Overview
Illumin Eye Mobile is a cross-platform mobile surveillance application built with **Flutter** and **Dart**. It integrates with custom hardware using **Arduino**, **ESP32 microcontroller**, and **ESP32-CAM** module to enable real-time monitoring and surveillance capabilities.

## Key Technologies & Stack
- **Frontend/Mobile**: Flutter (Dart) for cross-platform development (Android, iOS, web, desktop support)
- **State Management**: BLoC pattern for robust, scalable state handling
- **Hardware/Firmware**: Arduino-compatible C++ code for ESP32 and ESP Camera integration
- **Other**: CMake for build configuration, platform-specific code (Swift for iOS, etc.)

## Main Features
- Real-time video streaming and control from ESP32-CAM
- Mobile interface to interact with and monitor the surveillance hardware
- Inclusion of Arduino firmware directly in the repository for seamless hardware-software integration
- Full IoT-based surveillance system combining mobile app with embedded hardware
